# I AM LIGHT Web Solutions

A responsive business website for I AM LIGHT Web Solutions.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year

## Before publishing
1. Replace `2547XXXXXXXX` in `index.html` with your real WhatsApp number.
2. Replace `hello@iamlightwebsolutions.com` with your real email.
3. Replace the demo portfolio names/images with your real work.
4. Push the files to a GitHub repository.
5. Enable GitHub Pages from the repository's Settings → Pages.
